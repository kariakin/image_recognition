# image_recognition
distinguishing between paintings and printed reproductions
Приложение должно работать так: 1.После нажатия на кнопку "защита"  приложение включает камеру с фонариком, пользователь показывает общий план на котором есть прямоугольная картина. 2. Приложение обнаруживает объект "Картина" и обводит его в прямоугольную пунктирную желтую рамку, если объект не обнаружен - возврат назад. 3. По мере приближения камеры к картине после того как картина займет все поле изображения, приложение вычисляет на полотне множество фичей для использования их в дальнейшем для поиска этого в объекта в базе и позиционирования,  находит на полотне картины (ближе к центральной части чтобы убрать помехи от рамки картины) область с максимальной энтропией и вычисляет фичи вокруг этой области что бы их использовать в дальнейшем для поиска этой области на полотне картины и позиционирования.Пунктирная рамка должна исчезать и появлятся только в том случае если граница картины появляется в кадре 4. После обнаружения области максимальной энтропии приложение обводит эту область зеленым квадратом и просит пользователя приблизится к этой зоне. 5, По мере приближения камеры к этой зоне зеленый квадрат должен быть зафиксирован на этой области картины при сдвигах изображения и изменении масштаба. 6. После максимально возможного приближения камеры к этой зоне с сохранением резкости изображения пользователь нажимает кнопку  съемки и приложение просит пользователя сделать 5 снимков с небольшими сдвигами в разные стороны. 7. Приложение использует эти 5 снимков для вычисления оценки 3D поверхности картины (включен источник света-фонарик, камера перемещается почти парралельно поверхности картины, яркость точек поверхности меняется в зависимости угла нормали к поверхности и положения источника). 8. Если поверхность картины является 3D с достаточными перепадами уровней, принимается решение о возможности защиты картины, из пяти снимков выбирается наилучший, на этом снимке выбирается небольшая зона 256х256 точек (эталонное изображение) без зеркальных отражений с хорошим перепадом яркости и наличием высокочастотных составляющих в пространственном спектре. 9. Приложение просит пользователя указать название картины. 10. Координаты зеленой зоны в картине, координаты эталонного изображения в зеленой зоне, фичи всей картины, фичи зеленой зоны, эталонное изображение дата и время защиты записываются в базе данных сервера.  Приложение сообщает пользователю об успешной защите картины. 11. После нажатия на кнопку "Проверка" приложение включает камеру с фонариком, пользователь показывает общий план на котором есть прямоугольная картина подлинность которой нужно проверить.Приложение обнаруживает объект "Картина" и обводит его в прямоугольную пунктирную желтую рамку.  12. По мере приближения камеры к картине после того как картина займет все поле изображения, приложение вычисляет на полотне множество фичей для использования их для поиска этого в объекта в базе. 13. Приложение производит поиск этого объекта в базе данных, если изображение объекта не найдено, приложение просит пользователя указать название картины, если объект по названию не найден, приложение сообщает об этом пользователю и выходит в окно приветствия, если объект найден приложение продолжает проверку.  находит на полотне картины зеленую зону по координатам.  14. После обнаружения зеленой зоны и отображения ее на экране на полотне картины приложение  просит пользователя приблизится к этой зоне. 15, По мере приближения камеры к этой зоне зеленый квадрат должен быть зафиксирован на этой области картины при сдвигах изображения и изменении масштаба. 16. После максимально возможного приближения камеры к этой зоне с охранением резкости изображения пользователь нажимает кнопку  съемки и приложение просит пользователя сделать 5 снимков с небольшими сдвигами в разные стороны. 17. Приложение использует эти 5 снимков для вычисления оценки 3D поверхности картины (включен источник света-фонарик, камера перемещается почти парралельно поверхности картины, яркость точек поверхности меняется в зависимости угла нормали к поверхности и положения источника). 18. Если поверхность картины является 3D с достаточными перепадами уровней, принимается решение о возможности проверки картины, из пяти снимков выбирается наилучший, на котором наилучшим образом отображения эталонная зона координаты которой извлекаются из базы. По фичам производится коррекция геометрических искажений и масштаба и вырезается   эталонное изображение  без зеркальных отражений с хорошим перепадом яркости и наличием высокочастотных составляющих в пространственном спектре. 19. Приложение сравнивает между собой тестовое изображение и иэталонное и принимает решение о подлинности картины.
